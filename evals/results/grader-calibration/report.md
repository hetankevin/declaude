# Grader calibration

Ten fixed synthetic cases contain a usable and a flawed response each. Six cases are calibration-development and four are validation. Expected assertions and score bands were written before either grader ran. These are assistant-authored reference judgments, not independent human labels. Neither grader was revised after seeing the validation outcomes.

Both graders matched all 22 expected assertion judgments. The original grader matched 19/20 holistic score bands; v2 matched 20/20. On validation alone, the rates were 7/8 and 8/8. The one difference concerns a valid proof that put two equalities on one display line despite a request for separate lines: v1 scored it 3, whereas the predeclared band and v2 score were 4. Both correctly failed its formatting assertion. Both penalized the incorrect proof.

This is a small calibration improvement, not evidence of broadly reliable grading. v2 explicitly separates meaning from rhetorical packaging and mathematical correctness from exposition, while retaining strict checks for actual changes in conditions or guarantees. Its greater clarity and complete calibration match support using it for the next development comparison and fresh test. The original ten-configuration benchmark keeps v1 grades. Never interpret score differences across graders as skill improvements.
