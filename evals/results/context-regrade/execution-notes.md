A syntax-only recovery was added during execution: remove commas immediately before a closing array/object delimiter, outside JSON strings, then run the original strict parser and all evidence checks. Recovered records preserve the original raw hash and disclose the exact deleted character offsets in `json_syntax_repairs`. This is an execution-parser amendment, not a change to the judging criteria or retry allowance.

This formatting recovery uses no model calls and changes no reasons or preferences.
